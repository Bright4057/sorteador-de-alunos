🎓 Sorteador de lugares da sala

Cadastre os alunos, escolha o tipo de sala e sorteie os lugares. Você pode marcar alunos que devem ficar separados.

1. Alunos e regras

O programa tenta colocar esses alunos o mais longe possível uns dos outros. O resultado é uma tentativa aleatória, não uma garantia matemática.

Clique em uma cadeira para ativá-la ou desativá-la. Cadeiras cinzas não entram no sorteio.

Ao aproximar um vértice de uma mesa do vértice de outra, eles se alinham automaticamente. Você pode desativar esse recurso quando quiser.

Clique em um objeto para selecioná-lo; use Shift+clique para adicionar/remover objetos da seleção, ou arraste sobre o espaço vazio para selecionar vários com uma caixa, como no Canva. Use Ctrl/⌘+G para agrupar e Ctrl/⌘+Shift+G para desagrupar. Use Ctrl/⌘+D ou o botão Duplicar para copiar um objeto ou grupo. Arraste o ícone ↻ acima da seleção para girar um objeto ou grupo inteiro. Esc limpa a seleção. Para mover o mapa, use o botão do meio do mouse.

Adicione os nomes dos alunos para começar.
